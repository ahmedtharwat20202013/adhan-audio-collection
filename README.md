# Adhan Audio Collection

Private personal collection of Adhan/Azan MP3 recordings gathered from public repositories.

## Sources

- [Kiwifu/adhan-mp3](https://github.com/Kiwifu/adhan-mp3) — described by its author as 200+ recordings for Islamic apps, prayer-time software, and personal use. The source repository does not expose a standard license in GitHub metadata.
- [abodehq/Athan-MP3](https://github.com/abodehq/Athan-MP3) — contains MP3 files under `Sounds/`; GitHub metadata does not expose a standard license.
- [dalba0/hayya](https://github.com/dalba0/hayya) — includes `adhan-regular.mp3` and `adhan-fajr.mp3`; see [its audio README](https://github.com/dalba0/hayya/blob/main/src/assets/audio/README.md).

## Important rights notice

This repository is private. “Free” or public availability does not by itself establish permission to redistribute or use a recording commercially. Before making this collection public, shipping it in an application, or redistributing individual files, verify the rights for each recording and preserve any required attribution. Files are retained with source prefixes where needed to avoid filename collisions.

## Contents

All audio files are in [`audio/`](audio/). A generated manifest with SHA-256 checksums is in [`sources/manifest.tsv`](sources/manifest.tsv).
